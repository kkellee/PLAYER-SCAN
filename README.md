# PLAYER SCAN

PLAYER SCAN is a Dota 2 player analysis project. This first version is the public-facing landing page; the Steam profile scan is not wired up yet.

## Current scope

- Dota-inspired responsive landing page
- Steam ID / profile URL input validation
- Profile scan placeholder state

## Run locally

Open `dist/index.html` in a browser or serve the `dist/` directory with any static HTTP server.
